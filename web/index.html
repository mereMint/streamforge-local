Cloud credentials stay inside rclone's protected Termux configuration. StreamForge stores only the connected remote name and folder.

Guided connection

Connect Google Drive

NOT CONNECTED

Start the guided login, then open Google's authorization link on the Android phone running StreamForge.

Open Google sign-in on phone

The authorization callback listens only on 127.0.0.1 on the phone. If this dashboard is open on a PC, open the generated link on the phone or use the documented SSH tunnel. Full Drive access is optional and broader than backups need.

Archive contents

What gets backed up

ARCHIVE CONTAINS SECRETS
  • The server environment and credentials
  • The database, overlay profiles, uploads, and logs
  • Existing backup archives are excluded

A direct Google Drive remote protects transport but does not encrypt the archive in your Drive. For private cloud storage, wrap the connected Drive in an rclone crypt remote and select that remote for backups.
